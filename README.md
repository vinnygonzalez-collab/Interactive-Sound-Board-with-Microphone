🎛️ Dynamic Audio Visualizer

The soundboard features a central circular visualizer that bridges the gap between audio and visuals. Powered by the HTML5 Web Audio API and rendering via custom CSS animations, the visualizer reads real-time frequency data to create an immersive experience:
• Pulsing Ring Element: A stylized center ring that expands, glows, and scales in perfect synchronization with the audio amplitude 
(volume peaks).
• Web Audio API Integration: Leverages an AudioContext and AnalyserNode to dissect live audio frequencies with zero performance lag.

• HTML5: Semantic structure and audio element integration.
